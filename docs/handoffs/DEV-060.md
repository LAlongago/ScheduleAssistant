## 完成内容与关键设计选择

- 新增独立 Application 周期契约、系列 DTO/命令、`IRecurrenceUseCases`、`IRecurrenceMaterializer` 与事务内物化端口；继续复用既有 `RecurrenceSeries`、`RecurrenceRule`、`OccurrenceDateCalculator` 和 `TaskItem`，没有建立平行 Domain 模型。
- 实现系列创建、读取、更新、停用、单实例删除和未来范围删除；系列与实例删除/更新均通过既有版本字段和仓储映射返回冲突/未找到/存储错误。
- 物化默认窗口为本地今天前 31 天至后 400 天，支持每日、每周多星期、每月指定日和每年指定日；月末与闰年钳位继续由 Domain 计算器负责。实例是普通 `TaskItem`，保存 `SeriesId`/`OccurrenceDate`，不从发生日期推导 Deadline，也不会为无 Deadline 的实例建立提醒。
- 物化使用排除日期和 SQLite `series_id + occurrence_date` 唯一约束的 `INSERT ... ON CONFLICT DO NOTHING`，配合进程内门闩支持重复/并发调用幂等；事务内重新读取系列，避免停用或更新竞态写入旧规则实例。
- 启动初始化完成后执行默认物化；日历日期、周、月和今日查询按所需日期范围触发一次性物化，没有新增高频轮询计时器。
- 编辑周期实例沿用普通任务编辑流程并自动标记 `IsOccurrenceOverride`；“修改此后”只删除并重建指定日期后的普通未完成实例，保留历史、已完成和覆盖项。删除单实例在同一事务写入排除并删除 Task；删除未来范围截断/停用系列并保留已完成历史，后续物化不会重新生成。
- 事务提交后发布 `RecurrenceSeriesChanged`、`TaskCreated`/`TaskDeleted` 刷新事件；提交前失败会回滚且不发布成功事件，提交后订阅者失败遵循既有 `RefreshRequired` 语义。
