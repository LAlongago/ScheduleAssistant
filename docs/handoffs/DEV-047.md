## 完成内容与关键设计选择

- 为 `Expander.OptionalCard` 的展开状态设置一致的 `MinHeight=370`，该高度覆盖当前“内容”分区的三组文本框和间距。
- 分区收起时不设置最小高度，仍保持紧凑标题卡片；任一分区展开时预留相同高度，因此只展开 Deadline 后再展开内容，Deadline 不会再次变高。
- 结合 DEV-046 的 `VerticalAlignment=Stretch` 规则，两个分区同时展开时仍共享 Grid 行高并保持等高；若未来内容超过最小高度，Grid 行高仍可自然增长。
- 增加测试断言：单侧展开时收起分区没有最小高度，双侧展开后实际高度差不超过 0.1，重新收起后状态恢复。
- 更新唯一产品规范和 README，将 DEV-047 登记为 V1.0 Presentation 布局修订。
