## 已完成

- 新增普通任务新建/编辑编辑器窗口、`TaskEditorViewModel` 和复用入口 `ITaskEditorService`。
- 新建入口接受预填计划日期，编辑入口接受任务 ID；`MainWindow` 的“新建任务”按钮已接入真实服务。
- 表单覆盖标题、类型、优先级、计划日期/起止时间/地点、Deadline、本机 Windows 时区、提醒开关/偏移、具体事务、材料准备、备注。
- 类型选项通过 `GetCategoryOptionsAsync` 加载，保存只调用 `ITaskUseCases.CreateAsync/UpdateAsync`；ViewModel 未引用仓储、SQLite 或文件系统。
- 新建状态固定为 `Pending`；编辑时只读展示现有状态，未增加绕过状态用例的状态写入入口。
- 附件和周期区域为明确禁用的契约占位，分别标注 DEV-070 和 DEV-061，未伪造持久化。
- 实现 UI 校验、Application 错误展示、Deadline 早于计划日期确认、DST 无效时间修改提示、DST 歧义时刻显式选择并以 `ConfirmedUtc` 提交。
- 保存失败保留输入；乐观并发冲突显示错误并提供重新加载；取消/窗口关闭对脏表单进行放弃确认；成功保存关闭窗口并通过 `TaskEditorSavedEventArgs` 保留 `PostCommitEventStatus/RequiresRefresh`。
- 运行时组合使用同一 `TaskUseCases` 实例注册 `ITaskUseCases` 与 `ITaskQueries`，同一 `InProcessEventBus` 实例注册 `IApplicationEventPublisher`；HostedService 在解析主窗口及页面图前只初始化一次数据库。
- 新增不可变的 `002_seed_default_categories.sql`，固定六个默认类型 ID、名称、顺序和合法 `#RRGGBB` 颜色，使用 `INSERT OR IGNORE` 保证幂等，未修改 `001_initial_schema.sql`。
