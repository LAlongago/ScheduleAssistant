## 完成内容与关键设计选择

- 将任务编辑器外层 `ScrollViewer` 的 `VerticalScrollBarVisibility` 从 `Auto` 改为 `Hidden`，隐藏滚动条但保留鼠标滚轮、键盘和触控滚动能力。
- WPF 的 `Hidden` 模式不会让垂直滚动条在内容溢出时动态占用布局宽度，因此 Deadline/内容分区展开前后，两列的可用宽度保持稳定，不再向左挤压。
- 为滚动容器增加稳定的 `x:Name`，并在窗口级 Presentation 测试中锁定 `Hidden` 配置；没有改变编辑器内容、分区高度或滚动方向。
- 更新唯一产品规范和 README，将 DEV-045 登记为 V1.0 Presentation 布局修订。

参考资料：

- [Microsoft WPF `ScrollBarVisibility` 文档](https://learn.microsoft.com/en-us/dotnet/api/system.windows.controls.scrollbarvisibility?view=windowsdesktop-10.0)
