## 完成内容与关键设计选择

- 今天页通过 `ITaskQueries` 读取 `GetTodayPendingAsync`、指定本地日期 `GetCalendarDateAsync` 和 `GetDeadlinesAsync(All)`；使用 Application 返回的 `CalendarEntry.IsPlannedOnDate`、`IsDeadlineOnDate`、`DisplayStatus` 和 `DeadlineUrgency` 分组，不按标题去重。同日计划与 Deadline 只建立一张卡并显示两个标记，完成区默认折叠。
- 今天页区块顺序为最近 Deadline 缓存倒计时、已逾期、计划已过、今日计划、今日 Deadline、已完成；倒计时保留最近项及最多 3 项，无 Deadline 时显示轻量提示。
- 即将截止页使用 `DeadlineQueryRange` 提供 24 小时、3 天、7 天、30 天和全部范围，分别显示 Application 已排序的逾期/即将截止结果，不在 Presentation 重排。
- 页面均通过 `PageStatePresenter` 覆盖 Loading/Empty/Error/Ready。查询和数据库初始化异步执行，数据库初始化由单例 gate 保证只执行一次。
- `TaskCardMapper` 只把 Application DTO/派生值映射为展示字段；真实卡片持有任务 ID/version，通过现有完成/取消完成用例操作。成功使用返回 DTO 和新 version，冲突、失败、取消或异常恢复复选框并显示安全错误。
- 任务事件订阅使用同一 `InProcessEventBus`，刷新在 `IUiDispatcher` 上应用，订阅和计时器随页面释放。分钟 tick 只更新缓存倒计时；最近未来 Deadline 使用 `TimeProvider` 支持的单次计时器触发重新查询。
- 组合根独立提交 `ba1c47d` 注册同一 `TaskUseCases` 到 `ITaskUseCases`/`ITaskQueries`，并注册同一事件总线到 `IApplicationEventPublisher`；实现提交随后补充 Presentation 计时、Dispatcher 和映射注册。
