- 用真实的 `MonthPageViewModel` 和 `MonthView` 替换占位页；查询只通过既有 `ITaskQueries.GetMonthCalendarAsync`，日期详情只通过 `GetCalendarDateAsync`，Presentation 未引用 Domain、仓储或 SQLite。

- 日期头和 `+N` 都在当前月页打开详情面板；详情完整加载当天事项，并在紧凑卡片旁复用现有完成命令。
- 数据库初始化完成后异步查询；任务事件的 `AffectedDates` 与当前 42 天网格相交时局部刷新，不使用轮询；详情、月页均保留 Loading/Empty/Error/Ready 状态。
- 查询/详情实现拆到同一 ViewModel 的 partial 文件，保持生产文件低于 500 行。
