## 关键设计选择

- 目标框架采用当前规格日期下的稳定 LTS .NET 10：跨平台项目使用 `net10.0`，WPF 项目与架构测试使用 `net10.0-windows`。
- 通过 `EnableWindowsTargeting=true` 保留非 Windows 构建代理的编译可能性；实际 WPF 运行和 Windows API 冒烟仍限定在 Windows 10/11 x64。
- Presentation 对 Infrastructure 的引用只出现在组合根注册路径；View/ViewModel 尚未创建，也没有任何具体仓储、SQLite 或 Windows 适配器。
- 使用程序集 marker 作为当前空项目的最小可测试依赖锚点，避免为了满足架构测试而虚构业务接口或模型。
- `Directory.Packages.props` 预先集中登记 Host/DI、MVVM、SQLite、Dapper 和测试工具链版本；DEV-001 只实际引用 Host/DI 与 xUnit 测试包，未实现持久化。
