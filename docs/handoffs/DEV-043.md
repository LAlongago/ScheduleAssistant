## 完成内容与关键设计选择

- 依据 Microsoft Windows 官方排版指导，为简体中文界面设置 `Microsoft YaHei UI, Segoe UI Variable, Segoe UI` 字体栈；等宽数字使用 `Cascadia Mono, Consolas`。WPF 的逗号分隔字体族用于缺字回退。
- 新增统一的扁平化选择控件资源：现代 ComboBox/ComboBoxItem、四位数字选择框、DatePicker、分段范围按钮和卡片式 Expander。实窗验收时发现自定义 ComboBox 一度把选中项显示为对象调试文本，随后补齐 `ItemTemplateSelector` 传递并用窗口级测试锁定“科研 / 一般”等显示文本。
- 新增 `DigitalTimePicker`，分别选择 `HH:mm` 的四个数字；小时十位为 2 时，小时个位自动限制为 0–3。控件继续通过双向 `TimeText` 依赖属性适配现有 ViewModel 文本契约，不修改 Application/Domain 接口。
- 任务编辑器移除右上角状态提示与基本信息中的只读工作流状态；状态仍由既有任务动作和领域模型维护。
- 基本信息/执行计划、截止与提醒/内容、附件/周期分别放入同一网格行和等宽列；同排区域共享行高。截止与提醒、内容改为可选 Expander，默认收起。
- 计划日期和 Deadline 日期使用统一扁平 DatePicker；计划开始、计划结束和 Deadline 时间使用四位数字选择器。启用 Deadline 但未选择时间时显示明确校验消息，避免空时间进入草稿构造。
- 即将截止页默认 7 天且只暴露 24 小时、3 天、7 天；Presentation 会拒绝 30 天或全部等未展示范围。既有 `DeadlineQueryRange` 值继续供今天页等内部场景使用。
- 更新唯一产品基线和 README，将以上变更登记为已批准的 V1.0 Presentation 修订。
