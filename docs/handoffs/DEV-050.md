## 完成内容与设计选择

- 用真实周历替换 Week 占位页，固定构造周一至周日七个 `WeekDayViewModel`，保留 Application 返回的日期顺序和 `CalendarEntry` 聚合/排序语义；Presentation 不复制日期去重或排序逻辑。
- `WeekPageViewModel` 通过 `ITaskQueries.GetWeekCalendarAsync` 获取周数据，并并行获取分类选项；不直接访问仓储、SQLite 或 Domain。
- 周页内部提供上一周、下一周和回到本周导航。七列使用等宽 `UniformGrid`，页面只设置一个垂直 `ScrollViewer`，避免每列独立滚动。
- 新增周历专用紧凑卡片，复用现有 `TaskCardViewModel`、`ITaskCardMapper` 和完成/取消完成 Application 用例。计划事项显示 `●`，Deadline 显示 `◆`；同一 `CalendarEntry` 的双标记只渲染一张卡。
- 继续使用既有页面状态、设计 token、数据库初始化等待和 `InProcessEventBus`。任务事件的 `AffectedDates` 命中当前周时刷新，提醒计划事件按当前查询语义忽略；没有轮询计时器。
- 保留无参数 `WeekPageViewModel` 构造路径以兼容既有 Shell 测试，生产组合根继续使用参数化构造。
