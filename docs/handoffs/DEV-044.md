## 完成内容与关键设计选择

- 新增 `ShowValidationErrors` 和 `IsFormPromptVisible` 状态。编辑器初始化时仍可计算字段错误以支持数据绑定，但表单提示和错误红框均保持隐藏；用户点击保存后才显示非法字段反馈，保存按钮不再因初始校验错误而被禁用。
- 在通用 TextBox、ComboBox、DatePicker 和四位时间选择器上复用条件错误模板，错误边框由 ViewModel 的保存尝试状态控制；异常加载、冲突和保存失败消息仍可独立显示。
- 为 Deadline 与内容 Expander 设置顶部对齐并补充窗口级测试，确保一侧展开时另一侧保持独立收起，不再被同一 Grid 行拉伸成空白卡片；移除“可选·点击展开”提示。
- 移除任务编辑器中本机 Windows 时区的展示提示，将界面字段和校验消息统一为“提醒时间”。底层 `ReminderOffsetMinutes` 和 Deadline 时区字段保持不变，未修改 Application/Domain 合同。
- 新增主题化的 `ConfirmDiscardChangesWindow`，以应用字体、颜色、圆角和按钮样式替换原生 MessageBox；“继续编辑”和“放弃修改”仍保持原有取消/确认语义。
- 更新唯一产品规范和 README，登记 DEV-044 的 V1.0 变更边界。
